# Glossaire — Français (fr)

Statut : machine-translated (model), pending human review
Registre : vouvoiement. Typographie : espace insécable (U+00A0) avant « : » et « % » et à l’intérieur des guillemets « », espace fine insécable (U+202F) avant ; ? !, apostrophe typographique ’.

| English | Français | Justification |
|---|---|---|
| Focus | Concentration | Traduction retenue par Apple (mode Concentration) ; « Focus » est un anglicisme. |
| Session | Séance | Plus naturel que « session » pour un temps de travail ou de révision. |
| Pomodoro | Pomodoro | Nom propre de la méthode, non traduit. |
| Task | Tâche | Terme universel. |
| Project | Projet | Terme universel. |
| Due date | Échéance | Terme courant et court en gestion de tâches. |
| Reminder | Rappel | Terme système standard. |
| Repeat | Répétition | Libellé de champ nominal, plus idiomatique. |
| Note | Note | Terme universel ; le module s’intitule « Mes notes » et le champ de tâche « Remarques ». |
| Notebook | Carnet | Métaphore physique courte et naturelle. |
| Tag | Étiquette | Évite l’anglicisme « tag » ; « Libellé » est réservé aux labels de tâches. |
| Label | Libellé | Distingue les labels de tâches (façon Gmail) des étiquettes de notes. |
| Deck | Paquet | Terme utilisé par Anki en français. |
| Card | Fiche | « Fiche de révision » est l’usage scolaire en France ; aussi pour « Flashcards ». |
| Review | Révision / Réviser | Usage naturel pour l’étude. |
| Again / Hard / Good / Easy | Encore / Difficile / Bien / Facile | Libellés d’Anki en français, courts pour les boutons. |
| Goal | Objectif | Terme standard. |
| Target | Objectif / Cible | « Objectif quotidien » pour la concentration, « Cible » pour la valeur numérique d’un objectif. |
| Habit | Habitude | Terme universel. |
| Streak | Série | Terme utilisé par Duolingo et les apps d’habitudes. |
| Insights | Statistiques | Clair et descriptif pour le module d’analyse. |
| Backup | Sauvegarde | Terme système standard. |
| Restore | Restaurer | Terme système standard. |
| Trash | Corbeille | Terme système standard. |
| Archive | Archiver | Verbe standard. |
| Pin | Épingler | Terme standard (Android, messageries). |
| Assistant | Assistant personnel | Précisé pour le titre du module ; « assistant » seul dans les phrases. |
| AI provider | Fournisseur d’IA | « IA » est le sigle français standard. |
| On-device | Sur l’appareil | Indique un traitement local. |
| Time block | Plage horaire | Expression française naturelle pour un créneau réservé. |
| Break | Pause | Terme naturel pour la méthode Pomodoro. |
| Pause (button) | Suspendre | Verbe d’action court, opposé à « Reprendre ». |
| Settings | Réglages | Terme d’iOS en français, plus court que « Paramètres ». |
| Erase word | EFFACER | Mot court en majuscules à saisir pour confirmer. |
