# Glossário — Português do Brasil (pt, conteúdo pt-BR)

Status: machine-translated (model), pending human review
Tratamento: você. Vocabulário brasileiro (aparelho, tela, excluir, salvar, configurações, lixeira, backup). Aspas “ ”.

| English | Português (BR) | Justificativa |
|---|---|---|
| Focus | Foco | Termo usado pela Apple em pt-BR (modo Foco); curto para a navegação. |
| Session | Sessão | Termo direto e comum. |
| Pomodoro | Pomodoro | Nome próprio da técnica, não traduzido. |
| Task | Tarefa | Termo universal. |
| Project | Projeto | Termo universal. |
| Due date | Prazo | Curto e natural no Brasil. |
| Reminder | Lembrete | Termo padrão dos sistemas. |
| Repeat | Repetir | Verbo curto para o rótulo do campo. |
| Note | Nota | Termo universal; “Anotações” no campo de tarefa. |
| Notebook | Caderno | Metáfora física comum (OneNote, Evernote). |
| Tag | Etiqueta | Evita o anglicismo “tag”; usado em notas e cartões. |
| Label | Marcador | Termo do Gmail em pt-BR para labels de tarefas. |
| Deck | Baralho | Termo usado pelo Anki em português. |
| Card | Cartão | Evita o anglicismo; “Flashcards” vira “Cartões” no módulo. |
| Review | Revisão / Revisar | Uso natural ao estudar. |
| Again / Hard / Good / Easy | De novo / Difícil / Bom / Fácil | Rótulos curtos no estilo do Anki em pt-BR. |
| Goal | Meta | Mais comum que “objetivo” em apps de hábitos no Brasil. |
| Target | Meta / Alvo | “Meta diária” para foco; “Alvo” para o valor numérico de uma meta. |
| Habit | Hábito | Termo universal. |
| Streak | Sequência | Termo usado pelo Duolingo em pt-BR (“ofensiva” é marca própria). |
| Insights | Estatísticas | Claro e descritivo para o módulo de análises. |
| Backup | Backup | Anglicismo consolidado no Brasil (Android, WhatsApp). |
| Restore | Restaurar | Termo padrão. |
| Trash | Lixeira | Termo padrão do Android/Windows no Brasil. |
| Archive | Arquivar | Verbo padrão. |
| Pin | Fixar | Termo do WhatsApp e Android em pt-BR. |
| Assistant | Assistente | Termo direto. |
| AI provider | Provedor de IA | “Provedor” é o termo brasileiro para serviços. |
| On-device | No aparelho | “Aparelho” é mais natural que “dispositivo” no Brasil. |
| Time block | Bloco de tempo | Tradução aceita da técnica “time blocking”. |
| Break | Pausa | Termo natural no Pomodoro. |
| Timer | Temporizador / Timer | “Temporizador” como modo; “Timer de foco” em configurações (uso corrente no Brasil). |
| Settings | Configurações | Termo do Android em pt-BR. |
| Erase word | APAGAR | Palavra curta em maiúsculas para confirmar. |
