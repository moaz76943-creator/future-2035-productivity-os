# Arabic (ar) glossary — Future OS

Status: machine-translated (model), pending human review.
Register: Modern Standard Arabic, masculine-neutral imperative (common in apps). Western digits 0-9 only. Full CLDR plural forms (zero/one/two/few/many/other).

| English | Arabic | Rationale |
|---|---|---|
| Focus | التركيز | Standard, short; used for tab, timer and phase. |
| Session | جلسة | Common term for a timed work period. |
| Pomodoro | بومودورو | Technique name transliterated, as widely used. |
| Task | مهمة | Standard productivity term (plural مهام). |
| Project | مشروع | Standard term (plural مشاريع). |
| Due date | تاريخ الاستحقاق | Standard term in task apps; "مستحقة" for due items. |
| Reminder | تذكير | Standard notification term. |
| Repeat | التكرار | Neutral noun for recurrence settings. |
| Note | ملاحظة | Standard term (plural ملاحظات). |
| Notebook | دفتر | Short, natural container for notes. |
| Tag | وسم | Common for #hashtags; distinct from task "label" (تسمية). |
| Label | تسمية | Used for task labels to avoid clashing with tags. |
| Deck | مجموعة (بطاقات) | Clearer than literal "رزمة" for non-card-game users. |
| Card / Flashcard | بطاقة / بطاقة تعليمية | Short form in UI, full form for the module name. |
| Review | مراجعة | Standard for spaced-repetition study. |
| Again / Hard / Good / Easy | مجددًا / صعبة / جيدة / سهلة | Short button labels; adjectives agree with "بطاقة" (feminine). |
| Goal | هدف | Standard term. |
| Target (numeric) | الهدف اليومي / المستهدف | "المستهدف" for a goal's numeric target to avoid repeating هدف. |
| Habit | عادة | Standard term. |
| Streak | سلسلة | Common in Arabic habit apps; concise. |
| Insights | الرؤى | Calm, non-technical name for analytics. |
| Backup | نسخة احتياطية | Standard OS term. |
| Restore | استعادة | Standard OS term (trash and backup). |
| Trash | المهملات | Standard OS term for deleted items. |
| Archive | أرشفة / المؤرشفة | Verb noun for action, adjective for views. |
| Pin | تثبيت / المثبّتة | Standard mobile term. |
| Assistant | المساعد | Neutral, not anthropomorphic. |
| AI provider | مزوّد الذكاء الاصطناعي | Clear; "API" kept in Latin script as a technical term. |
| On-device | على الجهاز | Short badge, conveys local processing. |
| Time block | فترة زمنية | Natural phrasing for calendar time blocking. |
| Erase word | مسح | Single short word the user types to confirm. |
| Weekdays | ن,ث,ر,خ,ج,س,ح | Conventional one-letter abbreviations, Monday first. |
