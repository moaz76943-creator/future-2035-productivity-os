# Glossary — Simplified Chinese (zh, mainland China)

Status: machine-translated (model), pending human review.
Register: 你 (informal, friendly); full-width punctuation; Western digits with a space between number and Chinese text.

| English | 中文 | Rationale |
|---|---|---|
| Focus | 专注 | Standard term in Chinese focus/Pomodoro apps; short for tabs and buttons. |
| Session | 专注时段 | Clear timed-period meaning; "会话" sounds like chat/network sessions. |
| Pomodoro | 番茄钟 | The established Chinese name for the technique and timer. |
| Task | 任务 | Universal in mainland productivity apps. |
| Project | 项目 | Standard term. |
| Due date | 截止日期 | Common in task apps (滴答清单, Microsoft To Do). |
| Reminder | 提醒 | Standard system term. |
| Repeat | 重复 | Matches iOS/Android calendar wording. |
| Note | 笔记 | Standard for notes apps. |
| Notebook | 笔记本 | Natural container term, as in Evernote China (印象笔记). |
| Tag | 标签 | Standard; also used for task labels. |
| Deck | 卡组 | Established term in Anki-style flashcard apps. |
| Card | 卡片 | Natural and short; module name is 闪卡 (flashcards). |
| Review | 复习 | Learning context; more natural than 审阅. |
| Again / Hard / Good / Easy | 重来 / 困难 / 良好 / 简单 | Mirrors the Chinese Anki rating labels; short for buttons. |
| Goal | 目标 | Standard term. |
| Habit | 习惯 | Standard term; check-in is 打卡. |
| Streak | 连续记录 / 连续 N 天 | Natural phrasing used by habit apps. |
| Insights | 洞察 | Concise, conveys analysis rather than raw statistics. |
| Backup | 备份 | Standard system term. |
| Restore | 恢复 | Used for both backups and trash. |
| Trash | 回收站 | Familiar from Windows and Chinese Android. |
| Archive | 归档 | Standard term. |
| Pin | 置顶 | Ubiquitous in Chinese apps (WeChat). |
| Assistant | 助手 | Neutral, not overpromising "AI". |
| AI provider | AI 服务商 | Clear that it is a third-party service the user chooses. |
| On-device | 本机处理 | Emphasizes that data stays on the phone. |
| Time block | 时间块 | Literal and established in time-blocking methods. |
| Event | 日程 | Calendar convention in mainland apps. |
| Spaces (hub) | 空间 | Short tab label for the module hub. |
| Erase word | 清除 | Typed confirmation word; easy to enter with any IME. |
