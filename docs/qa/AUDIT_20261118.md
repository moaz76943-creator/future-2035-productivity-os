# Technical and security audit — 2026-11-18

Scope: Android manifest and network config, database encryption and key handling,
encrypted backups, the optional remote assistant, notifications, logging, imports,
CI workflows, performance and layout on real devices (owner's screenshots).

## Fixed in this round

| Finding | Fix |
|---|---|
| QA APK was a **debug** build (JIT): slow start, janky transitions. | QA pre-release is now a **profile (AOT) build**, as smooth as the store build. |
| Each CI run signed the QA APK with a new random key, so a newer QA build could not be installed over the previous one. | One QA key kept in the Actions cache (never in the repository). The current test build must be uninstalled once. |
| Animated aurora background repainted every frame on every screen and forced the blurred navigation bar to re-blur continuously (GPU load, battery, jank). | Painted once in its own layer; navigation blur reduced and isolated. |
| Grey loading placeholders flashed on every navigation. | Shown only if loading takes longer than 220 ms. |
| Backup/restore ran Argon2id (19 MiB) on the UI isolate: the screen froze for seconds. | Key derivation runs on a background isolate. |
| Floating buttons on Tasks and Calendar were hidden behind the floating navigation bar. | Buttons inside the shell sit above the bar. |
| Large header left ~150 px empty above content; content scrolled visibly under the transparent header (e.g. the notification banner over the status bar). | Medium header with a solid background once content scrolls under it. |
| Spaces: "البطاقات التعليمية" and its caption were cut with an ellipsis at larger display sizes. | Two lines allowed; tile height follows the font scale. |
| "Link task" button overflowed at 150 % text on 360 px phones. | Wraps instead. |
| Assistant: response body was read without a size limit. | Bounded at 1 MiB; no redirects for the authorized request. |
| Card import split every line on the first `;`, had no quoted CSV, silently dropped bad lines and created duplicates. | RFC 4180 CSV/TSV with header detection, duplicates skipped (case/diacritics-insensitive), result reports imported / duplicates / incomplete rows; JSON format still accepted; 8 MiB limit. |
| CSV export could produce spreadsheet formulas. | Cells starting with `= + - @` (non-numeric) are neutralised. |

## Checked — no issue found

- Database encrypted with sqlite3mc; 256-bit key generated with `Random.secure()`, stored in Android Keystore-backed secure storage, validated as hex before use; an existing database is never paired with a new key.
- Backups: AES-256-GCM with the header as associated data, Argon2id KDF, header and size limits, bounded decompression, single-transaction restore, newer-schema backups rejected.
- `allowBackup=false`, cloud backup and device-transfer exclude all app data.
- Cleartext HTTP blocked by the network security config; the assistant accepts only `https://` URLs, asks consent per host, keeps the API key in secure storage.
- Only the launcher activity is exported; notification receivers are not exported.
- Notifications use private lock-screen visibility.
- No `print`/`debugPrint` of user data in `lib/`.
- Release builds can never fall back to the debug key (Gradle fails without upload credentials).
- CI: gitleaks secret scan on every push/PR; secrets only in the signed-release job.
